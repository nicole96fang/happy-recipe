# 🍯 幸福食谱 · Happy Recipe

> 一款可爱的本地化食谱工作台，无后端，无广告，所有数据保存在你的浏览器（IndexedDB）。

## ✨ 功能特性

- 🍱 **16 个食物分类**（鸡肉/猪肉/鱼肉/虾类/鱿鱼/螃蟹/蚌类/蔬菜/豆腐/鸡蛋/甜点/烘培/咖啡/饮料/面食/其它）
- ♾️ **无限食谱录入**，每道食谱支持：
  - 名称、份量、准备/烹饪时间、标签、收藏
  - 多张照片（自动压缩到 1600px、JPEG 0.85）
  - 美化食材排列 + 步骤自动编号 + 小笔记
- 🔍 **食谱搜索**（按名字/标签）
- ❤️ **收藏 / 取消收藏**
- ✏️ **编辑 / 删除 / 复制**
- 🖨️ **A4 打印** —— 自带收据风排版，全部照片排版美观
- 📤 **一键导出 PDF 分享**（jsPDF，含照片、自动分页）
- ☁️ **一键备份 / 恢复** —— JSON 文件，含所有照片（可换设备恢复）
- ❄️ **雪花动画**、🫧 **飘浮气泡**、💧 **水彩背景**
- 🐣 **圆润可爱 + 大按钮 + 圆角**
- 📱 **手机优先**（PWA，可"添加到主屏幕"）
- 💾 **IndexedDB 本地保存** —— 关闭页面/刷新后数据完全保留
- 🚫 **无后端 / 无广告 / 无 Sidebar** —— 打开即用

## 🚀 部署

任意静态托管都可以，例如 **GitHub Pages**、Vercel、Netlify、Cloudflare Pages。

### GitHub Pages 部署步骤
1. 进入仓库 **Settings → Pages**
2. Source 选择 `Deploy from a branch`
3. Branch 选择 `main` / `(root)`
4. 保存，等待 1-2 分钟即可访问

## 🧱 技术栈
- 纯 HTML / CSS / 原生 JavaScript（无任何前端框架）
- [jsPDF](https://github.com/parallax/jsPDF)（CDN 加载，用于 PDF 导出）
- IndexedDB（照片二进制本地保存）

## 🔒 隐私
所有数据都存在用户本机浏览器。没有任何后端，没有任何追踪，没有任何 cookie，没有任何广告。
